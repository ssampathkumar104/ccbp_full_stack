# Module 2, Topic 2.3 — Card-Based UI Patterns

---

## Core Concepts

A **card** is a contained box grouping related content — image, heading, text, and optionally a button or price. It's the most fundamental UI building block in this project.

### Three Card Patterns

| Pattern | Layout | Example |
|---------|--------|---------|
| **Vertical card** | Image on top, text below | Diwali shopping items, menu items |
| **Horizontal card** | Text on left, image on right (or vice versa) | Favourite Places, Flat listings |
| **Hero/Overlay card** | Card overlays a background image | Tourism card, Music page |

---

## Card Construction Recipe

Every card follows this mental model:

```
1. CONTAINER — background-color + border-radius + padding
2. SPACING — margin-bottom (between cards) or margin (around cards)
3. LAYOUT — default stacking (vertical) or d-flex flex-row (horizontal)
4. CONTENT — image + heading + description/price + optional button
5. TYPOGRAPHY — heading (large, dark, bold) vs body (small, gray, normal)
```

### Essential CSS Properties for a Card

```css
.card {
    background-color: white;       /* Stand out from background */
    border-radius: 8px;            /* Rounded corners */
    padding: 16px;                 /* Breathing room inside */
    margin-bottom: 15px;           /* Space between stacked cards */
}
```

### Pattern 2: Horizontal Card (Favourite Places)

```html
<div class="favourite-place-card-container d-flex flex-row">
    <div>
        <h1 class="favourite-place-card-heading">Taj Mahal</h1>
        <p class="favourite-place-card-description">Description...</p>
    </div>
    <img src="tajmahal.png" class="favourite-place-card-image" />
</div>
```

```css
.favourite-place-card-container {
    background-color: white;
    border-radius: 8px;
    padding: 16px;
    margin-bottom: 15px;
}
.favourite-place-card-image { width: 80px; height: 100px; }
```

Key technique: `d-flex flex-row` places text and image side-by-side. Inner `<div>` groups heading + description into one flex item.

### Pattern 3: Hero/Overlay Card (Tourism)

```html
<div class="bg-container d-flex flex-column justify-content-end">
    <div class="tourism-card">
        <h1>Tourism</h1>
        <p>Plan your trip.</p>
        <button>Get Started</button>
    </div>
</div>
```

```css
.tourism-card {
    text-align: center;
    background-color: white;
    padding: 5px;
    border-top-left-radius: 25px;
    border-top-right-radius: 25px;
    /* Bottom corners sharp — card is flush with viewport bottom */
}
```

### Pattern 4: Clickable Card with Navigation

```html
<div class="flats d-flex flex-row justify-content-between" onClick="display('section1Flat')">
    <img src="flat-image.png" />
    <div class="flat-description">
        <h1>3BHK Flat</h1>
        <p>Fully furnished house...</p>
    </div>
</div>
```

Entire card is clickable via `onClick` — navigates to detail view.

### Pattern 5: Shadow Card (Food Munch)

```html
<div class="shadow menu-item-card p-3 mb-3">
    <img src="..." class="menu-item-image w-100" />
    <h1 class="menu-card-title">Non-Veg Starters</h1>
    <a class="menu-item-link">View All →</a>
</div>
```

`shadow` = Bootstrap utility adding `box-shadow: 0 .5rem 1rem rgba(0,0,0,.15)`. Creates depth without visible borders.

## Color Hierarchy in Cards

| Element | Color | Weight | Size | Purpose |
|---------|-------|--------|------|---------|
| Heading | Dark (`#0f0e46`, `#323f4b`) | Bold | 23–30px | Grab attention first |
| Description | Gray (`#6c6b70`, `#7b8794`) | Normal | 13–15px | Supporting detail |
| Price/CTA | Dark or accent | Medium/Bold | 16px | Action/value item |

---

## Gotchas & Anti-Patterns

- **Card without padding** — content touches edges, looks cramped.
- **No margin between cards** — cards stack with no breathing room.
- **Inconsistent card sizes** — in a grid, all cards should have the same width.
- **Fixed widths on mobile** — `width: 140px` can overflow on tiny screens. Consider `max-width`.
- **`justify-content-between` for items that should be close** — this spreads items apart. Use no justify or `start` for items that belong near each other.

## Mastery Checkpoint — Answers

**Q1: Essential CSS properties that make something look like a card?**  
`background-color` (distinguishes from background), `border-radius` (friendly rounded corners), `padding` (internal breathing room), `margin-bottom` (space between cards).

**Q2: Why `d-flex flex-row` on outer container but NOT on inner text div?**  
If you add flex to the inner div, `<h1>` and `<p>` would sit side-by-side horizontally instead of stacking vertically (the natural/desired behavior for text content). The inner div should use default block stacking.

**Q3: Two separate `d-flex` rows vs Bootstrap grid (`col-6`) for the Diwali shopping?**  
- Two flex rows: Simple, fixed 2×2 layout. NOT responsive — always 2 per row on all screens.
- Bootstrap grid (`col-6 col-md-3`): Responsive — stacks on mobile, 4-across on desktop. Better for production but more complex.

The Diwali exercise sacrifices responsiveness for simplicity.

**Hands-On — Team Member Card:**

```html
<div class="team-member d-flex flex-row">
    <img src="profile.jpg" class="profile-image" alt="John Doe" />
    <div>
        <h2 class="member-name">John Doe</h2>
        <p class="member-role">Front-end Developer</p>
    </div>
</div>
```

```css
.team-member {
    background-color: white;
    border-radius: 10px;
    padding: 20px;
    margin-bottom: 15px;
}
.profile-image {
    width: 60px;
    height: 60px;
    border-radius: 50%;       /* Circle = 50% on a square element */
    margin-right: 15px;       /* Gap between image and text */
}
.member-name {
    font-weight: bold;
    font-size: 20px;
    color: #323f4b;
}
.member-role {
    font-weight: normal;
    font-size: 14px;
    color: #7b8794;
}
```

Key points:
- `border-radius: 50%` + equal width/height = circle
- `margin-right` on image creates gap (not `justify-content-between`)
- Use valid hex colors, not informal names like "dark"
