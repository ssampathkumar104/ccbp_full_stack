# Module 2, Topic 2.2 — Bootstrap 4 Grid System

---

## Core Concepts

The Bootstrap Grid gives you a **12-column responsive layout system**. You define how many columns each element takes at different screen sizes. The layout automatically adapts.

### The Three Required Layers

```html
<div class="container">           <!-- 1. Centered wrapper with max-width -->
    <div class="row">             <!-- 2. Flex row with negative margins -->
        <div class="col-6">      <!-- 3. Column taking 6/12 = 50% width -->
            Content
        </div>
        <div class="col-6">
            Content
        </div>
    </div>
</div>
```

Skipping any layer breaks the layout.

---

## The 12-Column Math

| Columns | Width | Items per row |
|---------|-------|---------------|
| `col-12` | 100% | 1 |
| `col-6` | 50% | 2 |
| `col-4` | 33.33% | 3 |
| `col-3` | 25% | 4 |
| `col-2` | 16.66% | 6 |
| `col-1` | 8.33% | 12 |

**Formula:** Items per row = 12 ÷ column number.

Columns in a row must add up to 12 (or less). If they exceed 12, extra columns wrap to the next line.

---

## Responsive Breakpoints

| Class prefix | Applies at | Typical device |
|-------------|-----------|----------------|
| `col-` | All sizes (0px+) | All |
| `col-sm-` | ≥576px | Phones (landscape) |
| `col-md-` | ≥768px | Tablets |
| `col-lg-` | ≥992px | Laptops |
| `col-xl-` | ≥1200px | Desktops |

Each breakpoint class overrides the previous at its minimum width. Classes apply **upward**.

---

## What Each Layer Does (Under the Hood)

```css
.container { max-width: 1140px; margin: 0 auto; padding: 0 15px; }
.row       { display: flex; flex-wrap: wrap; margin: 0 -15px; }
.col-6     { flex: 0 0 50%; max-width: 50%; padding: 0 15px; }
```

The grid IS flexbox under the hood. Column classes just set percentage widths.

## Grid + Flexbox Combined

Grid handles **macro layout** (column widths). Flexbox handles **micro layout** (arrangement within a column):

```html
<div class="container">
    <div class="row">                              <!-- GRID -->
        <div class="col-12 col-md-6">             <!-- GRID -->
            <div class="d-flex flex-row">          <!-- FLEXBOX inside grid -->
                <img src="..." />
                <div>
                    <h1>Feature</h1>
                    <p>Description</p>
                </div>
            </div>
        </div>
    </div>
</div>
```

---

## The `mb-3` Spacing Utility

`mb-3` = `margin-bottom: 1rem` (16px). Adds vertical space between cards when they wrap to new rows. Without it, stacked cards on mobile touch with no gap.

---

## Gotchas & Anti-Patterns

- **Columns without a row** — grid math breaks (missing negative margins).
- **Column numbers exceeding 12** — extra columns wrap to next line unexpectedly.
- **Forgetting `col-12` for mobile** — technically defaults to full-width, but being explicit is better documentation.
- **`container` vs `container-fluid`** — `container` has max-width + centering; `container-fluid` is always 100%.

## Mastery Checkpoint — Answers

**Q1: Element with `col-12 col-sm-6 col-md-4 col-lg-3` on 1024px screen?**  
1024px is in the `lg` range (≥992px, <1200px). `col-lg-3` applies → 3 columns wide = 25% width. Items per row: 12÷3 = **4 items**.

**Q2: Why must grid follow `container → row → col-*`?**  
- `container` → provides max-width, centering, side padding
- `row` → creates flex container, negative margins to counteract column gutters
- `col-*` → sets percentage width, adds gutter padding (15px each side)

Each layer solves a different part of the layout math.

**Q3: `col-6`, `col-3`, `col-3` → change first to `col-8`?**  
8+3+3=14 > 12. Third column wraps to next line. First row: col-8 + col-3 (=11). Second row: col-3 alone.

**Hands-On — Product Grid (1/row phone, 2/row tablet, 4/row desktop):**

```html
<div class="container">
    <div class="row">
        <div class="col-12 col-md-6 col-lg-3 mb-3">
            <h1>Product 1</h1>
        </div>
        <div class="col-12 col-md-6 col-lg-3 mb-3">
            <h1>Product 2</h1>
        </div>
        <div class="col-12 col-md-6 col-lg-3 mb-3">
            <h1>Product 3</h1>
        </div>
        <div class="col-12 col-md-6 col-lg-3 mb-3">
            <h1>Product 4</h1>
        </div>
    </div>
</div>
```

Key: `col-12` (phone, stacked) → `col-md-6` (tablet, 2/row) → `col-lg-3` (desktop, 4/row).  
Breakpoints: md=768px, lg=992px.
