# Module 2, Topic 2.4 — Bootstrap Navigation Bars

---

## Core Concepts

A navbar is the horizontal strip at the top containing logo and page links. Bootstrap's navbar component handles responsive behavior: **on large screens it shows all links in a row, on small screens it collapses into a hamburger menu**.

---

## Required Navbar Structure

```html
<nav class="navbar navbar-expand-lg navbar-light bg-white">
    <!-- 1. Brand/Logo (always visible) -->
    <a class="navbar-brand" href="#">
        <img src="logo.png" class="navbar-image" alt="" />
    </a>
    
    <!-- 2. Hamburger button (only visible on mobile) -->
    <button class="navbar-toggler" type="button" 
            data-toggle="collapse" 
            data-target="#navbarNav"
            aria-controls="navbarNav" 
            aria-expanded="false" 
            aria-label="Toggle navigation">
        <span class="navbar-toggler-icon"></span>
    </button>
    
    <!-- 3. Collapsible content (links) -->
    <div class="collapse navbar-collapse" id="navbarNav">
        <div class="navbar-nav ml-auto">
            <a class="nav-link active" href="#">Home <span class="sr-only">(current)</span></a>
            <a class="nav-link" href="#">About</a>
            <a class="nav-link" href="#">Contact</a>
        </div>
    </div>
</nav>
```

## Desktop vs Mobile Behavior

```
DESKTOP (≥992px with navbar-expand-lg):
┌──────────────────────────────────────────────────────────────┐
│ [LOGO]                              Home | About | Contact   │
│ (navbar-brand)                      (navbar-nav ml-auto)     │
│                                                              │
│ [hamburger button is HIDDEN]                                 │
└──────────────────────────────────────────────────────────────┘

MOBILE (<992px):
┌──────────────────────────────────┐
│ [LOGO]                    [≡]    │  ← hamburger visible
└──────────────────────────────────┘
        Click ≡ ↓
┌──────────────────────────────────┐
│ [LOGO]                    [≡]    │
├──────────────────────────────────┤
│ Home                             │  ← links expand vertically
│ About                            │
│ Contact                          │
└──────────────────────────────────┘
```

## Class-by-Class Reference

| Class | Applied to | Purpose |
|-------|-----------|---------|
| `navbar` | `<nav>` | Base navbar styling (flexbox, padding) |
| `navbar-expand-lg` | `<nav>` | Collapse below 992px, expand at ≥992px |
| `navbar-light` | `<nav>` | Dark text on light background |
| `navbar-dark` | `<nav>` | Light text on dark background |
| `bg-white` / `bg-dark` | `<nav>` | Background color |
| `navbar-brand` | `<a>` | Logo area — always visible |
| `navbar-toggler` | `<button>` | Hamburger button — hidden on desktop |
| `navbar-toggler-icon` | `<span>` | The ≡ icon (3 horizontal lines) |
| `collapse navbar-collapse` | `<div>` | Wrapper that collapses/expands |
| `navbar-nav` | `<div>` | Container for nav links |
| `ml-auto` | `<div>` | Pushes nav links to the RIGHT |
| `nav-link` | `<a>` | Individual navigation link |
| `active` | `<a>` | Highlights current page link |
| `sr-only` | `<span>` | Screen-reader-only text |
| `fixed-top` | `<nav>` | Sticks navbar to top when scrolling |

## The Toggle Mechanism

The button and collapsible content are connected by matching IDs:

```html
<button data-target="#navbarNavAltMarkup">     <!-- targets this ID -->
<div id="navbarNavAltMarkup">                  <!-- has matching ID -->
```

Bootstrap JS toggles visibility: `collapse` → `collapse show`.

**If `data-target` doesn't match any `id` → toggle breaks silently (no error).**

## `navbar-expand-*` Breakpoints

| Class | Collapses below |
|-------|----------------|
| `navbar-expand-sm` | 576px |
| `navbar-expand-md` | 768px |
| `navbar-expand-lg` | 992px (this project's default) |
| `navbar-expand-xl` | 1200px |

## Light vs Dark Navbars

| | Light | Dark |
|--|-------|------|
| Text/icon color | Dark | Light/white |
| Pair with | `bg-white`, `bg-light`, light custom | `bg-dark`, dark custom |
| Class | `navbar-light` | `navbar-dark` |

**Wrong combo:** `navbar-dark` + `bg-white` = invisible white text on white background.

## Examples from This Project

### Light Navbar (Portfolio)

```html
<nav class="navbar navbar-expand-lg navbar-light bg-white">
```
- Dark text, white background, collapses below 992px.

### Dark Navbar (Food Munch)

```html
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
```
- Light text, dark background.

### Fixed Navbar (Food Munch Full Page)

```html
<nav class="navbar navbar-expand-lg navbar-light bg-white fixed-top">
```
- Sticks to viewport top when scrolling. Content may hide behind it — add `padding-top` to body.

### Custom Background Color

```html
<nav class="navbar navbar-expand-lg navbar-dark" style="background-color: #0c0521;">
```
- When using a custom hex color, don't use `bg-dark`. Apply color directly via style or custom class.

## Accessibility Attributes

```html
<button aria-controls="navbarNav"       <!-- What this button controls -->
        aria-expanded="false"           <!-- Current state: open/closed -->
        aria-label="Toggle navigation"> <!-- Describes button for screen readers -->
```

Bootstrap JS auto-updates `aria-expanded` on toggle.

---

## Gotchas & Anti-Patterns

- **Mismatched `data-target` and `id`** — hamburger click does nothing. No console error.
- **Missing jQuery/Popper/Bootstrap JS** — hamburger visible but non-functional. Desktop layout still works.
- **`navbar-dark` + light background** — invisible text. Always match dark text with light bg, light text with dark bg.
- **`fixed-top` without body padding** — first page content hides behind the navbar (~56px overlap).
- **Using `bg-dark` for custom colors** — `bg-dark` is specifically `#343a40`. For custom hex values, use inline style or a custom CSS class.

## Mastery Checkpoint — Answers

**Q1: Role of `data-target="#navbarNavAltMarkup"`?**  
When the toggler button is clicked, Bootstrap JS finds the element with `id="navbarNavAltMarkup"` and toggles its visibility (adds/removes `show` class). If no element matches → toggle breaks silently.

**Q2: Difference between `navbar-light` and `navbar-dark`? Pair with navy blue?**  
`navbar-light` = dark text/icons for light backgrounds. `navbar-dark` = light text/icons for dark backgrounds. Navy blue (`#0c0521`) is dark → pair with `navbar-dark`.

**Q3: Remove all 3 JS files — what works, what breaks?**  
- **Still works:** Navbar renders on desktop (logo + links visible in a row). Visual structure intact.
- **Breaks:** Hamburger toggle does nothing on mobile. Links remain hidden. The interactive collapse behavior requires JavaScript.

**Hands-On — Photography Portfolio Navbar:**

```html
<nav class="navbar navbar-expand-md navbar-dark" style="background-color: #1a1a2e;">
    <a class="navbar-brand" href="#">
        <img src="logo.png" class="navbar-image" alt="Photography Logo" />
    </a>
    <button class="navbar-toggler" type="button" 
            data-toggle="collapse" data-target="#navbarNav"
            aria-controls="navbarNav" aria-expanded="false" 
            aria-label="Toggle navigation">
        <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="navbarNav">
        <div class="navbar-nav ml-auto">
            <a class="nav-link active" href="#">Gallery <span class="sr-only">(current)</span></a>
            <a class="nav-link" href="#">Pricing</a>
            <a class="nav-link" href="#">About</a>
            <a class="nav-link" href="#">Contact</a>
        </div>
    </div>
</nav>
```

Key points:
- `navbar-expand-md` → collapses below 768px (as required)
- Custom color via inline style (not `bg-dark`)
- `navbar-dark` for light text on dark background
- `sr-only` marks the active page for screen readers, not the link text
