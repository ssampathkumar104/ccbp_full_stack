# CCBP Full Stack — HTML & CSS Practice

## Introduction
This repository is a portfolio of hands-on front-end exercises and small projects focused on HTML, CSS, responsive layouts, and Bootstrap authored by S Sampath Kumar. It collects structured practice work and assignments that demonstrate core web layout and styling techniques, from basic semantic markup to responsive grid systems and component integration.

## What this repo contains
Top-level folders house grouped exercises and mini-projects:
- Bootstrap/ — Bootstrap-based practice pages and examples.
- HTML and CSS/ — Fundamental HTML & CSS examples (buttons, fonts, container elements).
- Responsive Web Design/ — Media-query driven exercises, grid system and navigation patterns.
- Website Integration/ — Integrated website pages and multi-section examples.
- Developing Layouts/ and Coding Mocktests/ — Layout practice and test-style exercises.

## Technical concepts covered
Below are the specific HTML/CSS topics and where you can find examples in the repository.

- Semantic HTML & document structure
  - Files: `HTML and CSS/index.html` and related practice pages.
  - Concepts: headings, paragraphs, buttons, semantic tags and content hierarchy.

- CSS fundamentals
  - Files: `HTML and CSS/style.css`, `Bootstrap/style.css`, `Website Integration/style.css`.
  - Concepts: selectors, specificity, the box model (margin, border, padding, content), colors, fonts and backgrounds (`index_font_details.html`, `index_container_element_color.html`).

- Styling interactive elements
  - Files: `HTML and CSS/index_button_details.html`
  - Concepts: buttons, hover/active/focus states, basic form control styling.

- Container & layout building blocks
  - Files: `HTML and CSS/index_container_element*.html`, `Developing Layouts/…`
  - Concepts: block vs inline, containing boxes, backgrounds, spacing, and nesting.

- Responsive layout techniques
  - Folders: `Responsive Web Design/`, `Responsive Web Design/GridSystem/`
  - Concepts: fluid layouts, media queries, breakpoints, mobile-first design, responsive navigation patterns (`NavigationBar/`).

- CSS Grid & layout systems
  - Folder: `Responsive Web Design/GridSystem/`
  - Concepts: two-dimensional layout using CSS Grid, responsive column behavior, and layout alignment.

- Bootstrap basics and utilities
  - Folder: `Bootstrap/`
  - Concepts: using Bootstrap classes for layout, responsive utilities, grid, and common components.

- Integration & multi-page sites
  - Folder: `Website Integration/` (includes a larger `index.html`)
  - Concepts: assembling pages into a cohesive site, shared stylesheet usage, site-level navigation, and page structure.

- Best practices touched on across exercises
  - Mobile-first thinking, progressive enhancement, separating structure (HTML) from presentation (CSS), and basic accessibility considerations (clear headings, semantic elements).

## How to view the examples
Open any HTML file in a browser, or serve the repository locally to test relative paths:

Open file directly:
- Double-click `<folder>/index.html` in your file manager or
- Drag the HTML file into your browser.

Serve locally (recommended for consistent behavior):
- From the repository root:
  - Python 3: `python -m http.server 8000`
  - Then browse: `http://localhost:8000/Website%20Integration/index.html` (or any other folder path)
