# Product Summary

This is a learning repository for the CCBP (Coding Challenges for Budding Programmers) "Introduction to HTML and CSS" course. It contains practice exercises, coding assignments, and mock tests that progressively cover:

- Basic HTML structure and elements
- CSS styling fundamentals (box model, backgrounds, fonts, colors)
- Bootstrap 4 framework usage (grid system, utilities, components)
- Flexbox layouts
- Responsive web design (media queries, breakpoints, grid system)
- Multi-page website integration with navigation
- CSS specificity and reusability
- Carousels, navbars, and embedded content

The exercises build static web pages — no backend or build tooling is involved. Each folder is a self-contained exercise with its own `index.html` and optional `style.css`.
