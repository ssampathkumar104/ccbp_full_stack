# Module 2, Topic 2.1 — Flexbox Layout (via Bootstrap Utilities)

---

## Core Concepts

Normal HTML stacks block elements vertically. Flexbox lets you arrange elements **side by side** or control their alignment along any axis.

In this project, flexbox is used through **Bootstrap utility classes**, not raw CSS:

| Bootstrap class | CSS equivalent | Meaning |
|----------------|----------------|---------|
| `d-flex` | `display: flex;` | "This element is now a flex container" |
| `flex-row` | `flex-direction: row;` | "Arrange children horizontally (left→right)" |
| `flex-column` | `flex-direction: column;` | "Arrange children vertically (top→bottom)" |
| `justify-content-start` | `justify-content: flex-start;` | "Pack items to the start" |
| `justify-content-center` | `justify-content: center;` | "Pack items to the center" |
| `justify-content-end` | `justify-content: flex-end;` | "Pack items to the end" |
| `justify-content-between` | `justify-content: space-between;` | "First item at start, last at end, space between" |

---

## Two Axes

When you add `d-flex`, two axes define layout:

```
flex-row:
  Main axis: ──────────────────────────────────► (horizontal)
  Cross axis: │
              ▼ (vertical)

flex-column:
  Main axis: │
             ▼ (vertical)
  Cross axis: ──────────────────────────────────► (horizontal)
```

- **`justify-content`** = alignment along the MAIN axis
- **`align-items`** = alignment along the CROSS axis

**Critical rule:**
- `flex-row` + `justify-content` = items move LEFT/RIGHT
- `flex-column` + `justify-content` = items move UP/DOWN

## Code Examples from This Project

### Pattern 1: Bottom-Anchored Content (Tourism Card)

```html
<div class="bg-container d-flex flex-column justify-content-end">
    <div class="tourism-card">
        <h1>Tourism</h1>
        <p>Plan your trip.</p>
        <button class="button">Get Started</button>
    </div>
</div>
```

- `flex-column` → main axis is vertical
- `justify-content-end` → push card to the BOTTOM

```
┌─────────────────────────────────┐
│    (background image fills      │
│     this empty space)           │
│                                 │
├─────────────────────────────────┤
│  Tourism                        │  ← pushed to bottom
│  Plan your trip.                │
│  [Get Started]                  │
└─────────────────────────────────┘
```

### Pattern 2: Horizontal Card (Favourite Places)

```html
<div class="favourite-place-card-container d-flex flex-row justify-content-between">
    <div>
        <h1>Taj Mahal</h1>
        <p>If there was just one symbol...</p>
    </div>
    <img src="tajmahal.png" class="favourite-place-card-image" />
</div>
```

- `flex-row` → horizontal
- `justify-content-between` → text left, image right

```
┌─────────────────────────────────────────────────┐
│ [Text div]                        [Image]       │
└─────────────────────────────────────────────────┘
```

### Pattern 3: Flexbox Alignment Variations (Mocktest)

```html
<div class="d-flex flex-row justify-content-start">
    <div class="box1">Box1</div>
    <div class="box2">Box2</div>
</div>
<div class="d-flex flex-row justify-content-center">
    <div class="box3">Box3</div>
    <div class="box4">Box4</div>
</div>
<div class="d-flex flex-row justify-content-end">
    <div class="box5">Box5</div>
    <div class="box6">Box6</div>
</div>
```

```
┌────────────────────────────────────────────────────┐
│ [Box1][Box2]                                       │  ← start
├────────────────────────────────────────────────────┤
│            [Box3][Box4]                            │  ← center
├────────────────────────────────────────────────────┤
│                                       [Box5][Box6] │  ← end
└────────────────────────────────────────────────────┘
```

### Pattern 4: Nested Flex (Selective Flexbox)

```html
<div class="card d-flex flex-row">     <!-- outer: flex horizontal -->
    <div>                               <!-- inner: NOT flex, stacks normally -->
        <h1>Title</h1>
        <p>Description</p>
    </div>
    <img src="..." />
</div>
```

Only the immediate layout level is flexible. Inner content stacks naturally.

## The Three Flex Patterns in This Project

| Pattern | Classes | Used for |
|---------|---------|----------|
| Bottom-anchored | `d-flex flex-column justify-content-end` | Tourism card, Music page, Flat booking |
| Side-by-side | `d-flex flex-row justify-content-between` | Place cards, flat listings |
| Centered | `d-flex flex-column justify-content-center` | Banner sections, hero text |

## Gotchas & Anti-Patterns

- **Forgetting `d-flex`** — `justify-content-*` does nothing without it.
- **Wrong level of flex** — Adding flex to an inner text div makes h1 and p sit side-by-side (usually unwanted).
- **`justify-content-end` vs `text-align: right`** — `justify-content-end` moves the entire box; `text-align: right` moves text within a box.
- **`justify-content-between` for close items** — Use it for "push apart" (logo left, nav right), NOT for items that should be near each other.

## Mastery Checkpoint — Answers

**Q1: Difference between `flex-row` and `flex-column` in terms of justify-content?**  
`flex-row` = main axis horizontal → `justify-content` moves items LEFT/RIGHT.  
`flex-column` = main axis vertical → `justify-content` moves items UP/DOWN.

**Q2: Tourism card with `justify-content-center` instead of `justify-content-end`?**  
The card would appear in the **vertical middle** of the screen (not bottom). With `flex-column`, justify-content operates vertically.

**Q3: Why `d-flex flex-row` on outer container but no flex on inner text div?**  
The inner `<div>` groups `<h1>` and `<p>` into ONE flex item. Without it, flexbox treats each child independently — you'd get three columns (h1 | p | img) instead of two (text-block | img).

**Hands-On — Logo left, nav links right:**

```html
<div class="d-flex flex-row justify-content-between">
    <img src="logo.png" alt="Company Logo" />
    <div>
        <a href="#">Home</a>
        <a href="#">About</a>
        <a href="#">Contact</a>
    </div>
</div>
```

`justify-content-between` with 2 flex items → first pushed to start, second pushed to end.
